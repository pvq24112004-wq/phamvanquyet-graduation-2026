# Thiệp mời tốt nghiệp – Phạm Văn Quyết

Website tĩnh dùng cho GitHub Pages.

## Cấu trúc

- `index.html`: nội dung website
- `assets/css/style.css`: giao diện
- `assets/js/app.js`: hiệu ứng, đếm ngược, nhạc và form RSVP
- `assets/images/`: hình ảnh
- `assets/audio/`: nhạc nền
- `google-apps-script/Code.gs`: mã lưu RSVP vào Google Sheets
- `SETUP_GOOGLE_SHEETS.md`: hướng dẫn kết nối Google Sheets

## Quan trọng

Form RSVP chỉ lưu dữ liệu sau khi bạn triển khai Apps Script và dán URL Web App vào `assets/js/app.js`. Xem `SETUP_GOOGLE_SHEETS.md`.


## Kết nối RSVP
Project này đã được cấu hình sẵn URL Google Apps Script để lưu phản hồi vào Google Sheets.
