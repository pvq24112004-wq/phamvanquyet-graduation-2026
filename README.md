# Thiệp mời tốt nghiệp – Phạm Văn Quyết

Website thiệp mời tốt nghiệp dành cho GitHub Pages.

## Cách đăng lên GitHub

1. Giải nén file ZIP.
2. Trong repository GitHub, chọn **Add file → Upload files**.
3. Tải lên toàn bộ nội dung bên trong thư mục này, giữ nguyên cấu trúc `assets/`.
4. Commit thay đổi và đợi GitHub Pages triển khai lại.
